# 隐私说明

更新日期：2026-11-04

DouyinPlus 是一个非官方、开源的第三方抖音客户端。项目**不运营服务器**，不收集、不上传、不出售任何用户数据。

## 1. 本机保存的数据

| 数据 | 位置 | 用途 |
| --- | --- | --- |
| 抖音登录 Cookie（含 `sessionid`、`ttwid` 等） | Android Keystore 加密的 `flutter_secure_storage`；隐藏 WebView 使用同一份 CookieManager | 维持登录态，请求推荐流、评论和互动接口 |
| 登录用户昵称、头像、抖音号、关注/粉丝统计 | 仅内存 | 在个人面板展示，App 关闭即丢失 |
| 评论、视频详情响应 | 仅内存，不持久化 | 当前评论面板展示 |
| 播放位置、当前视频索引 | 仅内存 | 本次会话的播放体验 |

App 不申请通讯录、位置、相机、麦克风、存储读写等权限；AndroidManifest 只声明 `INTERNET`。

## 2. 网络请求

App 直接与抖音官方域名及其 CDN 通信：

- `www.douyin.com`、相关 `douyin.com` 子域：登录页、推荐流、评论、详情、点赞/收藏
- 抖音视频/封面 CDN：媒体播放与图片加载

这些请求由本机发出，携带用户自己的 Cookie，与在浏览器中访问抖音等价。项目维护者无法看到请求内容，也不存在代理服务器、远程签名服务或 Cookie 上传接口。

GitHub 仅用于分发 APK 和源码；App 运行时不请求 GitHub，也不做自动更新检查（后续若加入，只会读取公开 Release 信息）。

## 3. 日志

- Release 构建不提供调试日志输出。
- Debug 构建可能打印视频尺寸、请求路径、状态码、耗时、响应长度。
- 代码不打印 Cookie、请求查询串、签名 token 或响应全文。
- 测试用的 HAR / CDP 抓包可能包含签名和登录态，**不要提交到仓库或公开分享**。

## 4. 删除数据

| 操作 | 效果 |
| --- | --- |
| App 内“退出登录” | 清除加密保存的 Cookie，并清空 WebView CookieManager |
| 系统设置 → 清除应用数据 | 清除 Cookie、缓存与本地设置 |
| 卸载 App | 删除应用私有目录，包括加密存储与 WebView 数据 |

重新登录需要再次在官方网页完成抖音登录。

## 5. 第三方与账号风险

- 本项目与抖音 / 字节跳动无任何关联，不代表官方。
- 抖音接口和风控策略可能随时变化。第三方客户端可能触发验证码、限制互动或账号风险。
- 点赞/收藏默认关闭，只在用户主动点击时发起单次请求，不做批量操作或后台自动互动。
- 评论发布、关注、私信、下载等功能不在当前范围。

## 6. 联系方式

如发现安全问题，请通过仓库的 Issue 或 Security Advisory 反馈。不要在公开 Issue 中粘贴 Cookie、`a_bogus`、`msToken`、HAR 或完整请求头。
