# DouyinPlus v0.2.1

修复评论区误报“需要完成抖音安全验证”，并默认开启点赞 / 收藏。

## 修复

- **评论/互动误报安全验证**：抖音正常页面里本来就有隐藏的验证码容器，v0.2.0 的检测把它当成真实验证页，导致登录后评论仍然提示“需要完成抖音安全验证”。
  现在只有在页面上真正可见（≥80px）的验证码元素或验证页标题才判定为风控，并提供更快的失败提示。
- **切换视频时的空值异常**：释放顺序错误导致 `AnimationController.stop` 抛异常、播放器可能未释放。已在 v0.2.0 修复，本版沿用。

## 新增 / 变更

- **点赞 / 收藏默认开启**：只在用户点击时发起单次写请求，请求中禁用同一按钮，失败自动回滚并提示。
- **初始状态同步**：进入视频时通过 `aweme/detail` 读取 `user_digged` / `user_collected`，首次点击发送的方向与页面显示一致，避免把已点赞视频点成取消。
- 互动可用编译开关关闭：`--dart-define=DOUYINPLUS_ENABLE_INTERACTIONS=false`。

## 验证

- 评论：`comment/list` 200（约 64KB），翻页 200（约 70KB），列表与页脚状态正常。
- 互动：点赞、取消点赞、收藏、取消收藏四条写路径均返回 HTTP 200 / `status_code=0`，无验证码触发，暖态耗时 300–400ms。
- 单元测试 33 个通过，`flutter analyze` 无问题。

## 已知问题

- 评论回复列表接口（`comment/list/reply`）仍会超时，当前只显示“共 N 条回复”提示，暂不能展开。
- 签名桥首次请求需要等隐藏 WebView 冷启动，可能数秒；失败后可在评论面板重试。
- 图文帖的图片暂未渲染（只显示背景）。
- 未做真机回归；当前验证环境为 Android 14 x86_64 模拟器（宿主 GPU）。

## 安装

要求 Android 7.0+。下载本页 APK 与 `.sha256`，先校验再安装。覆盖安装请使用同一签名。详细步骤与风险提示见仓库 `docs/install.md`，数据处理方式见 `docs/privacy.md`。

## 校验

```bash
sha256sum -c douyinplus-v0.2.1.apk.sha256
```
