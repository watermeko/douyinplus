# DouyinPlus v0.2.0

M2：评论浏览、互动基础与 GitHub Release 分发。

## 新增

- **评论区**：玻璃底部面板，支持评论分页、加载更多、空/错误状态；打开时暂停当前视频，关闭后恢复。
- **评论内容**：正文、图文/表情评论、作者头像与昵称、点赞数、回复数、时间与 IP 属地。
- **签名桥**：隐藏 WebView 在官方页面上下文执行需要 `a_bogus` / `msToken` 的请求；登录 Cookie 与本机 WebView 同步；检测验证码中间页并在重试时重载。
- **互动基础**：点赞 / 收藏请求、乐观更新与失败回滚已实现，但**默认关闭**（见下方说明）。
- **测试**：评论解析、分页去重、互动状态回滚、签名响应分类等单元测试。
- **发布工程**：release 签名配置、GitHub Actions tag 构建、APK SHA-256、安装与隐私文档。

## 重要说明

- **点赞 / 收藏默认关闭。** 开发期连续写入测试触发了抖音验证码，因此公开发布不默认启用写入。需要本地验收时可用
  `flutter build apk --dart-define=DOUYINPLUS_ENABLE_INTERACTIONS=true` 构建自用包，并只用自己的账号、低频操作。
- 点赞 / 收藏的初始状态未知（feed 不返回 `user_digged` / `user_collected`），按钮从“未点赞/未收藏”开始；首次点击会发送对应动作。
- 评论发布、关注、私信、下载不在本版本范围。

## 修复

- 横屏/方屏视频完整显示，使用模糊背景填充，不再裁切。
- 视频切换后的尺寸延迟问题：布局使用 feed 声明的宽高，视频就绪后淡入同一画框。
- 液态玻璃按钮统一为胶囊形，并保留按压回弹。

## 已知问题

- 评论回复列表接口（`comment/list/reply`）仍会超时，当前只显示“共 N 条回复”提示，暂不能展开。
- 签名桥冷启动首次请求可能需要数秒；失败后可在评论面板重试，必要时重载签名页。
- 互动开启后，如遇验证码/风控，操作会回滚并提示；不会自动重试或批量提交。
- 未做真机回归；当前验证环境为 Android 14 x86_64 模拟器。

## 安装

要求 Android 7.0+。下载本页 APK 与 `.sha256`，先校验再安装。覆盖安装请使用同一签名。详细步骤与风险提示见仓库 `docs/install.md`，数据处理方式见 `docs/privacy.md`。

## 校验

```bash
sha256sum -c douyinplus-v0.2.0.apk.sha256
```
