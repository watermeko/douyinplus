# 安装说明（Android）

## 1. 系统要求

- Android 7.0（API 24）及以上
- 能访问 `douyin.com` 及其视频 CDN 的网络
- 建议预留 150 MB 空间

## 2. 下载与校验

从仓库的 **Releases** 页面下载同一版本的两个文件：

- `douyinplus-vX.Y.Z.apk`
- `douyinplus-vX.Y.Z.apk.sha256`

先校验 SHA-256，确认 APK 未被篡改。

Linux / macOS：

```bash
sha256sum -c douyinplus-vX.Y.Z.apk.sha256
# macOS 若没有 sha256sum：shasum -a 256 douyinplus-vX.Y.Z.apk
```

Windows PowerShell：

```powershell
Get-FileHash .\douyinplus-vX.Y.Z.apk -Algorithm SHA256
```

将输出与 `.sha256` 文件中的值比较，必须完全一致。

## 3. 安装

1. 用文件管理器打开 APK。
2. 系统会提示“未知来源”。只对当前文件管理器授权，安装完成后建议关闭。
3. 确认安装。若已安装旧版且签名一致，会覆盖升级并保留登录态。
4. 首次启动点击「登录抖音账号」，在官方网页中扫码或使用验证码登录。

## 4. 升级

- 下载新 APK 直接覆盖安装即可，无需卸载。
- 不要混用不同签名的 APK；签名不一致时系统会拒绝安装。
- 若提示“应用未安装”，先确认 APK 与已装版本来自同一 Release 提供方，再尝试重启或清理安装器缓存。

## 5. 卸载与数据

卸载 App 会删除本机保存的登录 Cookie 和缓存，抖音账号本身不受影响。也可以在 App 内「退出登录」只清除本机登录态。

## 6. 已知问题

- 若评论区提示“需要完成抖音安全验证”，说明隐藏签名页被抖音风控拦截。请在 App 内「退出登录」后用官方网页重新登录并完成验证，再重试评论。
- 评论回复列表接口目前不稳定，可能只显示主评论。
- 点赞/收藏写入默认关闭；即使开启，抖音风控可能要求完成验证码。
- 隐藏的签名 WebView 首次请求可能较慢（冷启动数秒）；失败后可点评论面板的刷新/重试。
- 部分横屏视频使用“完整显示 + 模糊背景”，不会强行裁切。

## 7. 风险提示

这是第三方、非官方客户端，使用逆向得到的网页接口。抖音可能调整接口或风控策略，导致部分功能失效，也可能对账号触发验证码或限制。请仅使用自己的账号、保持正常人工操作频率；不要用于批量抓取、刷量、内容搬运或商业用途。详见 [隐私说明](privacy.md) 与仓库根目录免责声明。
